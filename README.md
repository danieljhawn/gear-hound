# Gear Hound

Gear Hound is a private, single-user dashboard for discovering used music gear and local barter opportunities.

## MVP scope

- Daily Austin/Cedar Park Craigslist collection
- Local Guitar Center used inventory
- Music gear priced at $500 or less
- FSOT/WTT discovery across all local Craigslist categories, especially Electronics and Barter
- Explainable matching against saved interests and a personal My Gear inventory
- Responsive phone and desktop interface
- Interested, Hidden, Barter, and Archived views
- Password-protected deployment at `gear.overstimulationstation.com`

## Planned stack

- Python 3.12 and FastAPI
- Jinja2 and HTMX
- SQLite and SQLAlchemy
- HTTPX with Playwright fallback
- Docker Compose
